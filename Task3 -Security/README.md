# Task 3 – Security Log Investigation

**Internship:** EdVyro Virtual Cyber Security Internship  
**Domain:** Cyber Security  
**Project:** Security Log Investigation

## 1. Objective

Analyze synthetic authentication logs to identify suspicious login behavior and reconstruct a possible security incident timeline.

## 2. Investigation Tasks

- Normalize timestamps, IP addresses, user accounts, actions, and result fields.
- Identify password spraying attempts.
- Detect possible brute-force attacks.
- Identify unusual successful login activity.
- Create an incident timeline.
- Separate confirmed evidence from assumptions.

## 3. Tools Used

- Python
- Visual Studio Code
- Windows PowerShell
- Authentication log files

## 4. Project Files

| File | Description |
|---|---|
| auth.log | Synthetic authentication events |
| normalize_logs.py | Log processing script |
| detection_rules.md | Detection rules |
| incident_timeline.md | Timeline of events |
| investigation_report.md | Final findings |

## 5. Expected Outcome

The investigation aims to identify suspicious authentication patterns, document relevant evidence, and provide a clear incident timeline.

## 6. Conclusion

This project demonstrates basic security log analysis, suspicious login detection, and incident investigation documentation.
