# EdVyro Virtual Cyber Security Internship

## Task 1: Threat Modeling and Secure Configuration

### Project Overview
This project focuses on identifying potential security threats in a Login Web Application using the STRIDE threat modeling methodology.

### Objectives
- Identify potential security threats.
- Analyze threats using the STRIDE framework.
- Rank risks based on likelihood and impact.
- Recommend security hardening measures.

### Tools Used
- diagrams.net — Threat model diagram
- GitHub — Project documentation and version control

### Task Deliverables

**Step 1: Threat Model Diagram**  
A diagram representing the Login Web Application and its main components.

**Step 2: STRIDE Threat Analysis**  
Potential threats categorized as:
- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service
- Elevation of Privilege

**Step 3: Risk Ranking**  
Threats ranked using likelihood × impact to identify high- and medium-priority risks.

**Step 4: Security Hardening Recommendations**
- Enable Multi-Factor Authentication (MFA).
- Use secure password hashing.
- Apply server-side input validation and parameterized SQL queries.
- Enforce authorization checks.
- Use HTTPS and secure session settings.
- Implement rate limiting and security logging.

### Conclusion
This task demonstrates a basic threat modeling workflow for a Login Web Application. The identified threats and risk ratings are illustrative and should be validated through security testing.
