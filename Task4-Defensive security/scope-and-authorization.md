# Scope and Authorization

**Project:** Defensive Security Assessment Capstone  
**Internship:** EdVyro Virtual Cyber Security Internship  
**Assessment Type:** Authorized Local Application Security Assessment

## 1. Purpose

The purpose of this assessment is to evaluate the security of my own locally developed Flask Secure Authentication application and identify potential security weaknesses.

## 2. Authorization Statement

I confirm that this assessment is performed only on my own locally developed application running in my local development environment.

No third-party applications, websites, servers, or systems will be tested.

## 3. Assessment Scope

The assessment includes:

- Application security configuration
- User authentication
- Session management
- Input validation
- Software dependencies
- Security logging and error handling

## 4. Rules of Engagement

1. Test only the authorized local application.
2. Do not access third-party systems.
3. Do not use real user credentials or personal data.
4. Avoid destructive testing.
5. Record test results accurately.
6. Document security weaknesses and recommended fixes.
7. Retest after applying security improvements.

## 5. Out of Scope

- Public websites and external servers
- Unauthorized network scanning
- Real customer information
- Production system testing
- Denial-of-service testing

## 6. Testing Environment

**Operating System:** Windows  
**Programming Language:** Python  
**Framework:** Flask  
**Development Tool:** Visual Studio Code  
**Environment:** Local development environment

## 7. Conclusion

This document establishes the boundaries and authorization for the defensive security assessment. All testing will remain within the defined local application scope.
