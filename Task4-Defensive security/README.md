# Defensive Security Assessment Capstone

**Internship:** EdVyro Virtual Cyber Security Internship

**Domain:** Cyber Security

**Project:** Defensive Security Assessment Capstone

## 1. Project Overview

This project focuses on performing an authorized defensive security assessment of my own locally developed Flask Secure Authentication application.

The objective is to identify security weaknesses, improve application security, and verify the implemented improvements.

## 2. Objectives

- Assess application security configuration.
- Review authentication and session management.
- Test input validation.
- Review software dependencies.
- Examine security logging.
- Identify and document security findings.
- Apply suitable security improvements.
- Verify the fixes through retesting.

## 3. Tools and Technologies

- Python
- Flask
- Visual Studio Code
- Windows PowerShell
- pip
- GitHub

## 4. Assessment Scope

The assessment is limited to my own local Flask authentication application.

Testing will focus on configuration, authentication, validation, dependencies, and logging.

## 5. Expected Deliverables

- Scope and authorization document
- Security assessment checklist
- Testing documentation
- Security findings
- Remediation report
- Final assessment report

## 6. Conclusion

This project provides practical experience in defensive security assessment, identifying application weaknesses, documenting findings, and verifying security improvements.

**Note:** Testing is restricted to the locally owned application. No third-party systems or real user credentials are involved.
