# Task 4 – Defensive Security Assessment Capstone

## Internship
EdVyro – Cyber Security Internship

## Project Overview
This project focuses on performing a defensive security assessment of a Flask-based authentication application.

The objective is to review application security, test authentication functionality, validate user inputs, analyze security logs, and identify possible security weaknesses.

## Objectives
- Assess authentication security.
- Test input validation.
- Review application configuration.
- Examine security logging.
- Identify potential vulnerabilities.
- Provide security recommendations.
- Prepare a final security assessment report.

## Assessment Activities

### 1. Authentication Testing
Review login functionality, invalid credentials, session handling, and logout.

### 2. Input Validation Testing
Check how the application handles empty fields, unexpected characters, and invalid inputs.

### 3. Configuration Review
Review application settings, secret key handling, debug mode, and session configuration.

### 4. Dependency Review
Examine the Python packages used by the application.

### 5. Logging Assessment
Review application logs and identify suspicious authentication activities.

## Scope and Authorization
All security testing is restricted to the locally hosted application owned or authorized by the project developer.

No unauthorized external systems are included.
